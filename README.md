# Full-Stack E-Commerce Storefront & Admin Dashboard

A full-stack e-commerce web application built with React, Tailwind CSS, and Supabase (PostgreSQL, Auth, and Storage).

## Tech Stack
- **Frontend:** React, React Router, Tailwind CSS
- **Backend / Database:** Supabase (PostgreSQL, Auth, Storage)

## Current Progress
- [x] Storefront product grid connected to Supabase
- [ ] URL-synced search, category filters, and product detail pages
- [ ] Role-based authentication (Customer vs. Admin)
- [ ] Database-synced persistent shopping cart
- [ ] Checkout flow and customer order history
- [ ] Admin dashboard (inventory management, image uploads, order fulfillment)
- [ ] TypeScript migration and Vercel deployment
